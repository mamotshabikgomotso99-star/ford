# Ford Automotive Experience

A frontend-only automotive website concept created as a personal portfolio project. It uses React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React. No backend, database, authentication, or API integration is included.

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

Create a production build with `npm run build`, or preview one with `npm run preview`.

## Media and attribution
